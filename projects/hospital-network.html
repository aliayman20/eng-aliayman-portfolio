Project overview

A simulated hospital network infrastructure designed with hierarchical topology, VLAN segmentation, Inter-VLAN Routing, DHCP, HSRP redundancy, STP stability, SSH remote management, CCTV, and IoT monitoring.

My role

I designed the hospital network simulation in Cisco Packet Tracer as part of my network design work, using a hierarchical topology with segmentation, redundancy, and secure remote management.

Main features & work completed

  • Hierarchical topology and VLAN segmentation.
  • Inter-VLAN routing and DHCP addressing.
  • HSRP redundancy and STP stability.
  • SSH remote management, CCTV, and IoT monitoring.

Technical details

The topology groups the hospital network into VLANs, with inter-VLAN routing for communication between segments. DHCP handles address allocation, HSRP provides gateway redundancy, STP supports a stable switching topology, and SSH enables remote management.

Results & outcome

The result is a simulated hospital network design, supported by a topology image and Packet Tracer file. It demonstrates infrastructure design work in a simulation environment.

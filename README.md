# Ali Ayman Portfolio Website

This is a static portfolio website built with HTML, CSS, Bootstrap, and JavaScript.

## Files
- `index.html` - main website page
- `style.css` - custom dark blue tech styling
- `script.js` - smooth navigation helpers
- `assets/images` - portfolio images
- `assets/cv/Ali_Ayman_Unified_CV.pdf` - unified CV

## Deploy on Netlify
1. Go to Netlify.
2. Choose "Add new site" > "Deploy manually".
3. Drag and drop the full `ali_portfolio_site` folder.
4. Netlify Forms will detect the contact form automatically after deployment.
5. Test the contact form from the live website, not from local files.

## Notes
- The contact form works only after deploying to Netlify.
- `store.da3m.net` LinkedIn post and video buttons are placeholders marked as Coming Soon.
